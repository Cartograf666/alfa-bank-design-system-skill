# Сторонний модуль figma-lean

`integrations/figma-lean/` включён из предоставленного архива
`figma-lean-skill-fixed.zip`, обозначенного в его README как исправленная сборка
от 8 октября 2026 года.

SHA-256 исходного архива:
`3d603bd46b7da985cf49a9838017b4d9ec2391d26fb24d7b91c88a1384d48f30`.

В архиве отсутствуют отдельная лицензия и сведения о правообладателе.
MIT из корневого `LICENSE` не назначается этому модулю. Перед отдельным публичным
распространением модуля необходимо уточнить условия у его правообладателя.

При включении сделаны следующие изменения:

- В справке `figma-lean/references/core-ds.md` наблюдения по внутреннему Figma-файлу,
  корпоративным библиотекам и токенам заменены правилами выбора источников проекта.
- В примере `codex/SKILL.md` явно передаются пути CLI и каталога данных, которые
  подставляет установщик. Это сохраняет выбранные пути при запуске моста.
- В `kit/kit.js` удалён один пробел в конце строки для проверки оформления diff.

Логика исполняемых файлов и исходные тесты сохранены. Проверки модуля
подтверждают локальную механику с имитациями API; они не подтверждают живой доступ
к Figma, визуальный результат или измеренную экономию токенов.
