# Исправления и остающиеся ограничения — 2026-10-08

Исходная версия содержала отчёт автора о 24 экранах и 4 ошибках в примерно 30 вызовах. Это историческое свидетельство автора, а не проверка исправленной сборки в Figma.

## Исправлено в этой сборке

- Scope: проверка родителя до `createInstance` и `combineAsVariants`.
- Paint binding: сохранение дополнительных заливок/обводок и явный выбор при неоднозначности.
- QA: проверка затронутых контейнеров после смены текста и явные границы проверки. Полные ID сохраняются из структурированного ответа в writes/, краткий отчёт даёт счётчики и путь.
- Пагинация: фрагментация крупного отдельного элемента, UTF-8 без потерь, учёт JSON-обёртки.
- Карта/дампы: сборка частей во временном snapshot и публикация целиком после завершения; проверка конфликтов и дубликатов. Изменившиеся usage-строки включаются в diff дайджеста.
- Поиск: вложенные JSON/MCP-ответы, большие результаты и доверенные локальные указатели на полный результат. Полные ключи сохраняются, вывод сокращается.
- Компоненты: резервные ключи и доступные главные компоненты; понижение нерабочего ключа для файла после успешного fallback.
- Рецепты: разрешение имён во вложенных исходниках; идемпотентная привязка всех совпадающих слоёв и проверка типов.
- Клоны: восстановление поддерживаемых property references, предупреждение при невозможности.
- Тексты: полное содержимое, смешанные диапазоны, имена стилей, все paints и variable aliases; явные preview; большой экспорт через фрагменты.
- Локальные блокировки: активная блокировка не отбирается по таймауту.
- Codex: отдельный программный мост; без изменения глобальных хуков, разрешений и Figma-плагина.

## Ограничения, которые нельзя выдавать за исправленные

- Настоящая Figma и визуальный результат этой сборки ещё не проверены. Локальные тесты используют mocks; они не подтверждают серверные особенности API, доступность шрифтов или авторизацию. Windows/Linux после правок не проверялись.
- Если хост не передал сырой большой ответ и не предоставил доступный доверенный файл, получить его через хук невозможно. Уменьшите запрос или используйте доступный локальный указатель. Произвольные URL и чужие журналы сессий не скачиваются/читаются.
- Scope защищает helper-вызовы. Сырой Plugin API-код и настройка scope остаются ответственностью вызывающего агента. Автоматического отката правок нет.
- Карта не синхронизируется с чужими правками автоматически. При изменении файла между частями snapshot отличается: пересканируйте. При неполном скане остаётся старая полная карта.
- Фрагментированные данные могут потребовать несколько обходов Figma; скорость и billed savings не измерены.
- QA остаётся эвристикой: не раскрывает все внутренности экземпляров по умолчанию, ограничивает число проверок и не оценивает визуальное качество. Смотрите макет при визуально значимых правках.
- Figma может запрещать изменение ссылок/размеров внутри экземпляра; кит предупреждает о неудачном восстановлении. Не обрезайте текст автоматически ради обхода проблемы.
- При исключении из Figma нерабочие ключи могут не вернуться в локальную телеметрию. Явный ключ остаётся способом выбора; новый search очищает отметку ошибки.
- Отсутствие отдельного helper для SLOT или определений компонента не является исправлением API Figma: для таких операций остаётся официальный Plugin API.
