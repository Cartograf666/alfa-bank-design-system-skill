# Устройство figma-lean

## Модули и данные

- `kit/kit.js`: Figma Plugin API helpers; выполняются в `use_figma`.
- `tools/lib.mjs`: сборка кода, разрешение имён/рецептов, карта, реестр, фрагменты и обработка MCP-ответа.
- `tools/hook.mjs`: Pre/PostToolUse адаптер для Claude Code.
- `tools/codex-bridge.js`: загружается внутри `functions.exec`, вызывает существующий официальный Figma-инструмент.
- `tools/fx.mjs`: CLI, подготовка/обработка JSON, самопроверка и символьная статистика.

По умолчанию данные Claude: `~/.claude/figma-lean`. Codex-мост задаёт `FIGMA_LEAN_HOME` в `${XDG_DATA_HOME:-~/.local/share}/figma-lean` (или `FIGMA_LEAN_HOME`).

`files/FILE_KEY/map.json`, `digest.md`, `config.json`, `notes.md`, `dumps/`, `writes/` — состояние файла; `ds/registry.json` — увиденные библиотечные ассеты; `recipes/` — рабочие рецепты; `log/` — исходные скрипты, статистика и ошибки. Полные результаты содержат данные макета: не публикуйте папку данных вместе с навыком.

## Подготовка и выполнение

`buildScript(fileKey,code)` проверяет синтаксис, добавляет kit только для `fx.*`, scope, имена ассетов и рекурсивные рецепты. Полная сборка ограничена 50 000 символов. Успешный результат с нерабочими ключами оборачивается в служебный envelope; исключения исходного скрипта не превращаются в успех.

Claude хук возвращает `updatedInput` без автоматического одобрения. Codex использует CLI `prepare` и прямой программный вызов инструмента: Claude `updatedMCPToolOutput` в Codex не поддерживается. Глобальные hooks/config не меняются.

`processToolOutput({toolName,fileKey,output,trustedPaths})` сохраняет данные и возвращает `{output,summary,changed}`. Соседние поля, текст и изображения MCP сохраняются. Codex-мост не передаёт base64 через shell и разбивает большие JSON-входы на временные части; при ошибке postprocessing возвращает исходный результат и предупреждение, не повторяя удалённый вызов.

## Части и сохранность

Capture получает стабильный snapshot содержимого. Крупные элементы делятся на строковые фрагменты без потери Unicode; каждый envelope проверяется по UTF-8 размеру. Части собираются под блокировкой, конфликт/смена snapshot не уничтожает прежнюю карту. Полная карта и дамп публикуются после завершения. Прерванные части не являются свежим состоянием; после изменения исходного файла нужен новый scan.

Индирекция поиска допускает только ограниченные доверенные локальные JSON/txt-файлы; произвольные URL и журналы чужих сессий не читаются. Если хост скрыл и данные, и файл, остаётся повторить меньший запрос.

## Изменения и проверки

Добавляйте общие операции в kit, конкретные повторяемые сценарии — в recipes. Перед мутацией проверяйте scope, заранее загружайте шрифты и сохраняйте валидные свойства. `fx.track` после операции не заменяет проверку до неё. Генерируйте `references/kit.md` и API-блок через `fx.mjs docs`; затем `doctor` и затронутые `tests/*.test.mjs`.

Не считайте PASS локальных тестов подтверждением серверного API, авторизации или визуального результата. Известные границы: [known-issues.md](known-issues.md).
