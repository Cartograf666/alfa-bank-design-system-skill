# Alfa core-ds: источники конкретного проекта

Применяй эту справку только к интерфейсам, для которых принадлежность к Alfa DS
подтверждена. Начинай с целевого Figma-файла, подключённых библиотек и решений
проекта; не переносись на другую библиотеку по совпадению названий.

Публичный источник компонентов: [core-ds/core-components](https://github.com/core-ds/core-components).
Сверяй его версию с проектом. Публичный исходник не раскрывает закрытые библиотеки,
их каталоги и токены и не доказывает соответствия конкретному Figma-файлу.

## Поиск и повторное использование

- `fx.mjs ds --libs` показывает сохранённые сведения о библиотеках; это кэш.
- `fx.mjs ds QUERY` и `fx.mjs comp QUERY` помогают повторно использовать найденные
  ассеты. При внешних правках или ошибке идентификатора пересканируй нужную секцию.
- Проверяй источник, платформу, тему, версию и актуальность компонента. При
  неоднозначности используй явный ключ из фактически полученного результата.
- Имена свойств, текстовых стилей и переменных бери из текущих источников.
  Не угадывай корпоративные имена и не превращай примеры в универсальные правила.
- Для сопоставления с кодом используй API и токены установленной версии пакета.
  `fx.mjs api` и `fx.mjs token` читают `node_modules` текущего проекта.

Цвета, типографика и иконки определяются дизайн-системой проекта.
Помощник сохраняет найденные ключи и выполняет операции; выбор дизайн-системы
и согласованные продуктовые решения остаются задачей основного навыка.
