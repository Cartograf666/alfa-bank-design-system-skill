# Alfa Bank Design System Skill

**От продуктовой задачи до макета в Figma и интерактивного HTML — по дизайн-системе Альфа-Банка.**

Переносимый неофициальный навык для **Codex** и **Claude Code**. Помогает
проектировать интерфейсы, собирать экраны из компонентов ДС, прорабатывать
значимые состояния и переносить согласованный дизайн в работающий HTML.
Работает самостоятельно или как часть существующей агентской обвязки.

> **Статус:** закрытая апробация. Формат, ссылки и инструкции проверены;
> практическая проверка на реальных продуктовых макетах — следующий этап.

## Для чего нужен

- **Обсудить решение:** получить макет, по которому команда может оценить структуру и логику интерфейса.
- **Проверить сценарий:** пройти значимые взаимодействия и состояния в прототипе.
- **Передать в разработку:** подготовить экраны, состояния и поведение, сохранив компоненты и правила ДС.
- **Сохранить контекст:** использовать вводные из задачи, существующего макета и решений проекта без повторного объяснения правил.

## Как работает

```text
Вводные и текущий макет
          ↓
Выбор: обсуждаем или сразу собираем
          ↓
Figma: экраны, компоненты, состояния и поведение
          ↓
Согласование с пользователем
          ↓
HTML по согласованному макету и проверка в браузере
```

Это основной процесс. Явный запрос пользователя может изменить последовательность
или ограничить работу одним форматом — например, только Figma или ранним HTML-прототипом.
При локальных правках навык сохраняет принятые решения и не начинает обсуждение заново.

## Что учитывает

| Область | Поведение |
|---|---|
| Компоненты | Переиспользует доступные компоненты, варианты и стили ДС |
| Цвета и типографика | Использует подтверждённые источники, учитывает тему и версию |
| Иконки | Уточняет набор, если он ещё не выбран, и сохраняет сделанный выбор |
| Продуктовая библиотека | Учитывает её компоненты и связи с общей ДС; не заменяет их общими аналогами автоматически |
| Вводные | Читает описание задачи, содержимое макета и решения проекта |
| Проверка | Отделяет созданный артефакт от реально проверенного результата |

## Установка

Клонируйте репозиторий. Пока он приватный, для клонирования нужен доступ к нему.

```sh
git clone https://github.com/Cartograf666/alfa-bank-design-system-skill.git
cd alfa-bank-design-system-skill
```

Скопируйте папку `skills/alfa-bank-design-system` **целиком** в каталог навыков:

| Среда | Для пользователя | Для проекта |
|---|---|---|
| Codex | `~/.agents/skills/alfa-bank-design-system` | `.agents/skills/alfa-bank-design-system` |
| Claude Code | `~/.claude/skills/alfa-bank-design-system` | `.claude/skills/alfa-bank-design-system` |

Для личной установки в Codex из корня репозитория:

```sh
mkdir -p ~/.agents/skills
cp -R skills/alfa-bank-design-system ~/.agents/skills/
```

Для личной установки в Claude Code:

```sh
mkdir -p ~/.claude/skills
cp -R skills/alfa-bank-design-system ~/.claude/skills/
```

Навык не требует обвязки автора или других навыков. Для выполнения действий
нужны доступные агенту средства чтения и редактирования Figma, работы с файлами
и проверки в браузере. Если операция недоступна, он обозначит ограничение;
подключение интеграций и изменение разрешений не происходят автоматически.

Формат и пути сверены с [документацией Codex](https://developers.openai.com/codex/skills)
и [Claude Code](https://code.claude.com/docs/en/skills).

## Использование

Описание позволяет среде выбирать навык по контексту UI Альфа-Банка.
Автовыбор зависит также от настроек и поведения самой среды. Ручной вызов:

- Codex: `$alfa-bank-design-system`.
- Claude Code: `/alfa-bank-design-system` в начале сообщения.

Примеры задач:

> Спроектируй экран настроек Альфа-Банка. Вводные есть в текущем макете Figma.

> Согласованный макет готов. Собери по нему интерактивный HTML и проверь основной сценарий.

> Поправь состояния таблицы в текущем интерфейсе Alfa DS, сохранив композицию.

## Доступ к дизайн-системе

| Доступ | Как работает навык |
|---|---|
| Есть доступ к корпоративной Figma | Использует доступные библиотеки файла и решения проекта |
| Нет корпоративного доступа | Работает по публичным источникам Core DS и обозначает ограничения |
| Нет инструмента для нужной операции | Продолжает доступные части и сообщает, что не создано или не проверено |

Пакет не предоставляет доступ к организации Альфа-Банка и не включает закрытые
библиотеки, шрифты, иконки, токен-дампы или внутренние каталоги. Наличие публичных
исходников Core DS не гарантирует точного воспроизведения закрытых компонентов.
Приватная видимость этого репозитория не расширяет права на сторонние материалы.

### Собственная библиотека продукта

Если у продукта есть отдельная библиотека, навык начинает с неё и подключённых
источников текущего файла. Он выясняет, какие компоненты принадлежат продукту,
какие приходят из общей ДС и какие связи нужно сохранить. Изменения общей ДС
не переносятся в продуктовую библиотеку автоматически: сначала проверяются
совместимость и затронутые компоненты.

## Состав

```text
skills/alfa-bank-design-system/
├── SKILL.md                    Инструкции и основной процесс
├── references/alfa-rules.md     Правила ДС, источники и уровни доступа
└── agents/openai.yaml          Необязательные метаданные Codex
```

Все обязательные правила находятся в `SKILL.md` и относительной справке
`references/alfa-rules.md`. `agents/openai.yaml` — необязательные метаданные
для Codex; поведение навыка от этого файла не зависит.

## Что уже проверено

- Структура навыка, метаданные и относительные ссылки.
- Переносимость формата по официальной документации Codex и Claude Code.
- Отсутствие персональных путей и корпоративных идентификаторов в комплекте.
- Инструкции на примерах старта задачи, раннего HTML и отсутствия корпоративного доступа.

Полное выполнение в Claude Code и практический цикл Figma → HTML пока не проверены.
Соответствие конкретной продуктовой библиотеке подтверждается в её рабочем файле.
