# figma-lean при сборке макета

Используй помощник, если он установлен, текущая среда предоставляет официальный
Figma-инструмент и этот способ подходит задаче. Основной навык определяет UX,
композицию, дизайн-систему и согласование; помощник выполняет повторяющиеся операции.
Установка и доступ не предполагаются автоматически.

## Рабочий проход

1. Загрузи установленную инструкцию `figma-lean`, а перед каждым `use_figma` —
   официальную `figma-use`. Соблюдай её текущие ограничения и контракт результата.
2. Начни с сохранённой карты нужного файла. При отсутствии карты, внешних правках
   или изменении структуры просканируй только нужную страницу или секцию.
   Карта — кэш; она не доказывает актуальное состояние файла.
3. Найди компоненты и токены в реестре, затем адресно прочитай нужные узлы.
   Сохраняй роль продуктовой библиотеки и явные ключи неоднозначных ассетов.
4. До правок укажи разрешённый корень. Создавай экземпляры и копии с явным
   родителем, чтобы они не попадали внутрь чужого фрейма.
5. Работай небольшими логическими партиями. Возвращай все `createdIds` и
   `changedIds` по официальному контракту; краткий QA — дополнительное поле.
   Учитывай ручные изменения Plugin API в полном списке идентификаторов.
6. После структурных правок обнови карту затронутой секции. Выполни короткую
   проверку сценария и вида, покажи макет. Длительный аудит начинай по правилу
   основного навыка: сначала объяснить находку и спросить о продолжении.

Для Codex установленная инструкция использует программный мост, для Claude Code —
его hooks. Применяй процедуру своей среды, не переносись между ними автоматически.

## Границы

- Scope проверяет helpers, но не изолирует произвольный Plugin API-код.
- QA эвристический и не заменяет просмотр переносов, композиции и читаемости.
- При ошибке обработки ответа сохранённый результат не означает неудачу удалённой
  правки. Проверь фактическое состояние до повторения; мост не повторяет write сам.
- Большие результаты передаются частями. Получи все части перед выводом о полном
  охвате. Недоступный полный ответ не восстанавливается догадками.
- Помощник не устраняет блокировку обязательной инструкции, отсутствие авторизации
  или недоступность Figma. Не обходи эти границы ради сокращения времени.
- Карты, код вызовов и выгрузки относятся к данным конкретной задачи. Храни их
  вне распространяемого пакета; не добавляй рабочий кэш в репозиторий навыка.

Модуль и процедуры установки находятся в `integrations/figma-lean/` исходного
репозитория. Для работы установленного основного навыка этот каталог не обязателен.
`stats` измеряет символы; экономия времени, токенов и денег отдельно не подтверждена.
